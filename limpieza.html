🗺️ 1. El mapa de la clase

La idea central: un pipeline no empieza con “hacer un DataFrame bonito”. Empieza con una fuente y termina con datos preparados para consumir.

1. Detectar
¿Qué problemas tienen los datos?
2. Decidir
¿Qué hacemos con cada problema?
3. Transformar
Aplicamos reglas reproducibles.
4. Validar
Comprobamos que el resultado tenga sentido.

Tipos, nombres, escalas, fechas, columnas derivadas y reglas de negocio.

🔎 2. Antes de limpiar: mirar el dato

Una limpieza responsable comienza con un diagnóstico. Si no sabemos qué hay, podemos eliminar información válida.

import pandas as pd
import numpy as np

df = pd.read_csv("ventas.csv")

print(df.head())
print(df.shape)
print(df.info())
print(df.isna().sum())
print(df.duplicated().sum())
print(df.describe())
Idea clave: dropna() no significa “siempre hay que borrar los nulos”. Primero hay que entender por qué están ahí.
🧠 Pregunta para la clase

Si una columna “edad” tiene 3 valores vacíos de 10.000 registros, ¿borrar esas filas siempre es correcto?

Respuesta para discutir: no necesariamente. Depende del objetivo, del significado del campo y de si podemos imputar el valor de forma razonable.

🕳️ 3. Valores nulos

df.isna().sum()
df.isnull().sum()
# Eliminar filas con algún nulo
df_limpio = df.dropna()

# Eliminar solo si falta una columna crítica
df_limpio = df.dropna(subset=["producto"])
# Ejemplo: reemplazar precio faltante por la mediana
df["precio"] = df["precio"].fillna(df["precio"].median())

# Texto faltante
df["ciudad"] = df["ciudad"].fillna("Desconocida")
💡 Regla práctica: eliminar, reemplazar o conservar un nulo depende del significado del dato. La decisión debe poder explicarse.

♻️ 4. Duplicados

Un duplicado puede ser un error… o puede representar una transacción legítimamente repetida. Hay que distinguir ambas situaciones.

# ¿Cuántos registros duplicados existen?
df.duplicated().sum()

# Verlos
df[df.duplicated(keep=False)]

# Eliminar duplicados exactos
df = df.drop_duplicates()

# Duplicados según una clave
df = df.drop_duplicates(subset=["id_venta"])
⚠️ ¿Por qué un duplicado puede ser peligroso?

Imagina ventas por $100.000. Si una venta aparece dos veces y calculamos ingresos sin revisar duplicados, el resultado podría quedar artificialmente inflado.

📈 5. Outliers con IQR

Un outlier no es automáticamente un error. Puede ser una compra extraordinariamente grande, un cliente especial o un dato mal registrado.

Q1

Percentil 25. Divide el 25% inferior de los datos.

Q3

Percentil 75. Divide el 75% inferior de los datos.

IQR

IQR = Q3 - Q1

Límites

Inferior = Q1 - 1.5×IQR
Superior = Q3 + 1.5×IQR

Q1 = df["total"].quantile(0.25)
Q3 = df["total"].quantile(0.75)

IQR = Q3 - Q1

limite_inferior = Q1 - 1.5 * IQR
limite_superior = Q3 + 1.5 * IQR

outliers = df[
    (df["total"] < limite_inferior) |
    (df["total"] > limite_superior)
]

print(outliers)
🎯 ¿Eliminar, corregir o conservar?

Eliminar: si se demuestra que es un error.

Corregir: si conocemos el valor correcto.

Conservar: si representa un comportamiento real.

🧪 7. Ejercicio 1 — Limpieza guiada

Usaremos un pequeño dataset con problemas intencionales.

data = {
    "id": [1, 2, 3, 3, 4, 5, 6, 7],
    "cliente": ["Ana", "Luis", "Marta", "Marta", "Pedro", None, "Laura", "Carlos"],
    "ciudad": ["Bogotá", "bogotá ", "MEDELLÍN", "MEDELLÍN", None, "Cali", "Bogotá", "Bogotá"],
    "cantidad": [2, 1, 3, 3, 2, 1, None, 100],
    "precio": [25000, 18000, 30000, 30000, 15000, 22000, 18000, 20000]
}

df = pd.DataFrame(data)

Problema A

Hay un cliente sin nombre.

Problema B

Hay un registro duplicado.

Problema C

Las ciudades tienen formatos diferentes.

Problema D

Hay una cantidad extremadamente alta.

👩‍💻 SOLUCIÓN — revelar después de intentarlo 
# 1. Diagnóstico
print(df.isna().sum())
print(df.duplicated().sum())

# 2. Eliminar duplicados
df = df.drop_duplicates()

# 3. Resolver nulos
df = df.dropna(subset=["cliente"])
df["cantidad"] = df["cantidad"].fillna(df["cantidad"].median())

# 4. Normalizar texto
df["ciudad"] = df["ciudad"].str.strip().str.lower()

# 5. Detectar outliers
Q1 = df["cantidad"].quantile(0.25)
Q3 = df["cantidad"].quantile(0.75)
IQR = Q3 - Q1

li = Q1 - 1.5 * IQR
ls = Q3 + 1.5 * IQR

print(df[(df["cantidad"] < li) | (df["cantidad"] > ls)])

La idea del pipeline

En lugar de escribir instrucciones sueltas cada vez, organizamos el proceso en funciones. Así podemos repetirlo cuando llegue un nuevo archivo o una nueva carga de datos.

import pandas as pd

def extraer():
    return pd.read_csv("ventas.csv")

def limpiar(df):
    df = df.drop_duplicates()
    df = df.dropna(subset=["producto"])
    return df

def transformar(df):
    df["precio"] = pd.to_numeric(df["precio"], errors="coerce")
    df["cantidad"] = pd.to_numeric(df["cantidad"], errors="coerce")
    df["total"] = df["precio"] * df["cantidad"]
    return df

df = extraer()
df = limpiar(df)
df = transformar(df)

print(df.head())
Una buena función hace una cosa clara. Esto facilita probar, modificar y reutilizar el pipeline.

🧩 9. Pipeline más robusto

def extraer(ruta):
    return pd.read_csv(ruta)

def limpiar(df):
    df = df.copy()

    # duplicados
    df = df.drop_duplicates()

    # texto
    df["producto"] = df["producto"].str.strip().str.title()

    # tipos
    df["precio"] = pd.to_numeric(df["precio"], errors="coerce")
    df["cantidad"] = pd.to_numeric(df["cantidad"], errors="coerce")

    # nulos
    df["precio"] = df["precio"].fillna(df["precio"].median())
    df["cantidad"] = df["cantidad"].fillna(0)

    return df

def transformar(df):
    df = df.copy()
    df["total"] = df["precio"] * df["cantidad"]
    df["fecha"] = pd.to_datetime(df["fecha"], errors="coerce")
    return df

def pipeline(ruta):
    datos = extraer(ruta)
    datos = limpiar(datos)
    datos = transformar(datos)
    return datos

resultado = pipeline("ventas.csv")

print(resultado.info())
print(resultado.head())
💡 ¿Qué ventaja tiene esto?

Si mañana recibimos otro CSV con la misma estructura, podemos reutilizar el proceso. El pipeline convierte una tarea manual en un procedimiento reproducible.

🌐 10. Del CSV a una API

La fuente puede cambiar. El concepto del pipeline permanece.

import requests
import pandas as pd

def extraer_api(url):
    respuesta = requests.get(url)
    respuesta.raise_for_status()
    return pd.DataFrame(respuesta.json())
CSV

Archivo local o recibido de otra fuente.

API

Datos obtenidos mediante una solicitud HTTP.

Scraping

Datos extraídos desde contenido web cuando está permitido.

def pipeline_api(url):
    datos = extraer_api(url)
    datos = limpiar(datos)
    datos = transformar(datos)
    return datos
La parte interesante es que Extract cambia según la fuente; Clean y Transform pueden mantenerse muy parecidos si la estructura final es compatible.
